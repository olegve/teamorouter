# TeamoRouter для DeepSeek Harness

Плагин нативно подключает [TeamoRouter](https://teamorouter.com/) к DeepSeek
Harness: добавляет провайдера и модели, показывает баланс, фактические
дневные/месячные затраты и оценку стоимости текущей сессии, хода и последнего
запроса хода.

Версия: `0.1.4`. Плагин распространяется как локальный bundle и не опубликован
в npm.

## Что делает плагин

- Добавляет страницу **Settings → TeamoRouter**.
- Сохраняет API-ключ TeamoRouter на Host и не возвращает его в браузер.
- Проверяет ключ через `GET /v1/models` и импортирует чат-модели.
- Создаёт провайдера `teamorouter` (OpenAI Chat Completions).
- Опционально создаёт отдельный маршрут `teamorouter-anthropic`
  (Anthropic Messages) для Claude.
- Не перезаписывает существующую конфигурацию `providers.teamorouter`:
  модели дополняются, пользовательские записи сохраняются.
- Показывает баланс аккаунта.
- Показывает фактические затраты за сегодня и текущий месяц: сумму, число
  запросов и токены.
- Показывает список моделей с протоколом, контекстом, vision и reasoning;
  выбранную модель можно сделать основной.
- Считает стоимость работы по фактическому `usage` из сессии и прайсу
  TeamoRouter:
  - стоимость сессии в строке под композером;
  - стоимость хода после завершённого хода;
  - стоимость последнего запроса хода в строке действий ответа.
- Сверяет оценку сессии с billing API по кнопке на чипе стоимости: показывает
  факт по ключу за период сессии, разницу и число запросов.
- Поддерживает русский и английский интерфейс.

## Чего плагин не делает

- **Не показывает точную сумму списания за конкретный запрос.** Это оценка
  `≈`. Для точной суммы нужен billing `request_id` из заголовка
  `x-request-id`, которого штатный LLM-адаптер DSH не отдаёт плагину.
- **Сверка с billing API не изолирует сессию.** `/v1/billing/costs`
  возвращает сумму по всему API-ключу за период; в неё могут попасть другие
  сессии, повторы и неудачные запросы. Поэтому факт показывается как «по
  ключу за период», а не как точная сумма этой сессии.
- **Не применяет peak/off-peak множитель.** Базовый прайс проверен на живом
  запросе; множитель `pricing_multiplier` пока не применяется, чтобы не
  занизить или не завысить оценку без подтверждённой семантики.
- **Не показывает live-тикер во время стриминга.** Стоимость обновляется
  после каждого `assistant/message`, когда уже известен `usage`.
- **Не считает затраты других провайдеров.** В сумму и чипы попадает только
  TeamoRouter.
- **Не добавляет image/midjourney/jev-модели** и не выполняет генерацию
  изображений.
- **Не является прокси** и не меняет маршрутизацию запросов за пределами
  настройки провайдера.
- **Не заменяет аккаунт DeepSeek** и штатный раздел «Аккаунт».
- **Не создаёт аккаунт TeamoRouter и не пополняет баланс.** Для пополнения
  плагин даёт ссылку на dashboard.
- **Не гарантирует точность до цента.** Фактическое списание всегда
  первично в dashboard и billing API TeamoRouter.

## Как считается стоимость

Для каждого assistant-сообщения TeamoRouter берётся `usage` и текущий прайс
`GET /v1/models/pricing`:

```text
cost =
    inputTokens      / 1e6 * price.input
  + cacheReadTokens  / 1e6 * price.cache_read
  + cacheWriteTokens / 1e6 * price.cache_creation
  + outputTokens     / 1e6 * price.output
```

Затем применяется контекстный тариф (`context_tier_pricing`), если входной
объём превысил порог. `price.cost` — уже дисконтированная цена TeamoRouter;
`list_cost` не используется.

`inputTokens` в DSH не включает cache read/write — это проверено на живой
сессии. Поэтому кэш не вычитается из `inputTokens` повторно.

Стоимость хранится в нано-долларах, чтобы длинные сессии не теряли точность.
В интерфейсе:

- `≈ $0.0042` — оценка;
- `—` — для модели нет цены;
- `*` — часть запросов в сумме без цены;
- фактические дневные/месячные суммы показываются без `≈`.

Фактические суммы за сегодня и месяц берутся из billing API и обновляются на
странице «TeamoRouter» раз в 60 секунд; после завершения хода Host сбрасывает
кэш, чтобы следующее обновление прочитало свежие данные.

### Сверка с billing API

Нажмите на чип стоимости сессии под композером. Плагин запросит
`/v1/billing/costs` за период от первого `turn/start` сессии до текущего
момента и покажет:

- оценку TeamoRouter;
- фактическую сумму по ключу за период;
- разницу и процент;
- число запросов в оценке и в billing.

Если запросов в billing больше, это нормально: туда могут входить генерация
заголовка, повторы, неудачные попытки и другие сессии. Ответ billing —
авторитетный для периода, но не является точной стоимостью одной сессии.

## Требования

- DeepSeek Harness с доступным менеджером плагинов (страница **Plugins** в
  сайдбаре или инструмент `plugin_manager`).
- API-ключ TeamoRouter вида `sk-teamo-...`.
- Сетевой доступ к `https://api.teamorouter.com`.

## Установка

Плагин лежит в подкаталоге `plugin/`. Устанавливать нужно именно его: в этой
папке находятся `package.json`, `cordis.patch.yml`, Host- и Client-части.

### 1. Клонировать репозиторий

```bash
git clone https://github.com/olegve/teamorouter.git
cd teamorouter
```

### 2. Установить bundle

**Через Web UI (рекомендуется):**

1. Откройте DSH.
2. В сайдбаре выберите **Plugins**.
3. Нажмите **Add plugin**.
4. В поле пакета укажите абсолютный путь к папке `plugin`, например:

   ```text
   /Users/you/src/teamorouter/plugin
   ```

5. Нажмите **Install** и дождитесь завершения.
6. Убедитесь, что bundle включён (при необходимости — **Enable now**).
7. Обновите страницу, если раздел **TeamoRouter** не появился сразу.

**Прямо из GitHub, без клонирования:**

В поле пакета в **Add plugin** можно указать Git-адрес с подкаталогом:

```text
git+https://github.com/olegve/teamorouter.git#path:/plugin
```

или:

```text
github:olegve/teamorouter#path:/plugin
```

Плагин лежит в подкаталоге `plugin/`, поэтому обычный URL репозитория без
`#path:/plugin` не сработает: в корне репозитория нет `package.json`.
Установка с этим fragment проверена через pnpm 11.28.5: ставится
`@local/dsh-teamorouter 0.1.4`. Если конкретная версия DSH не принимает
fragment в диалоге, используйте локальный клон и путь к `plugin/`.

**Через инструмент `plugin_manager`:**

```text
action: install_bundle
target: /absolute/path/to/teamorouter/plugin
```

Инструмент доступен не во всех пресетах и требует разрешения на управление
профилем.

**Через CLI:**

```bash
dsh plugin --profile desktop add /absolute/path/to/teamorouter/plugin
```

После `dsh plugin add` bundle нужно включить на странице **Plugins**: CLI
добавляет зависимость, но не выбирает bundle в профиле. Замените `desktop` на
имя своего профиля.

### 3. Подключить TeamoRouter

1. Откройте **Settings → TeamoRouter**.
2. Вставьте API-ключ `sk-teamo-...`.
3. При необходимости включите **Добавить Claude отдельным Anthropic-маршрутом**.
4. Нажмите **Подключить**.

Плагин проверит ключ, импортирует чат-модели и создаст провайдера. Если
провайдер уже был настроен, существующие записи сохранятся, а модели
дополнятся.

### 4. Проверить

- На странице **TeamoRouter** видны баланс, «Сегодня» и «Этот месяц».
- В селекторе моделей появились модели TeamoRouter.
- В строке под композером видна оценка стоимости сессии.
- После завершённого хода появляется строка стоимости хода.
- В строке действий ответа виден чип стоимости последнего запроса хода.

## Где смотреть стоимость

| Место | Что показывает |
|---|---|
| Строка под композером | Оценка стоимости всей сессии TeamoRouter |
| После завершённого хода | Сумма хода, число запросов и токены |
| Строка действий ответа | Стоимость последнего запроса хода |
| Страница «TeamoRouter» | Фактические суммы за сегодня и месяц |
| Карточка TeamoRouter на странице Models | Баланс, сегодня, месяц |

Чип у ответа относится к финальному assistant-сообщению хода. Полная стоимость
всех шагов и tool calls — в строке после хода.

## Обновление

```bash
cd teamorouter
git pull
```

Затем удалите и установите bundle заново через **Plugins** (Remove → Add
plugin → путь к `plugin/`) или через `plugin_manager` (`remove_bundle`, затем
`install_bundle`). Если профиль работает без HMR, перезапустите DSH.

## Удаление

1. **Plugins → Installed plugins → TeamoRouter → Remove**.
2. При необходимости удалите сохранённый ключ из credentials DSH
   (`TEAMOROUTER_API_KEY`).

Удаление bundle не удаляет ключ автоматически и не меняет уже созданного
провайдера в `llm-pi-ai`.

## Безопасность

- API-ключ хранится на Host в credentials DSH и не возвращается в браузер.
- BFF-маршруты плагина требуют авторизованного подключения к DSH.
- Плагин обращается только к `api.teamorouter.com`; телеметрии нет.
- Ключ не попадает в репозиторий: `.env`, `.DS_Store` и логи исключены
  через `.gitignore`.
- Стоимость — оценка, а не финансовый документ. Сверяйтесь с dashboard
  TeamoRouter.

## Разработка

Структура:

```text
plugin/
  index.js            Host: настройки, ключ, баланс, costs, проекция стоимости
  client.js           Client: страница TeamoRouter, чипы стоимости
  cordis.patch.yml    Host-запись bundle
  package.json        манифест и dsh.client
  locale/             локали
  icon.svg
test/
  cost.test.mjs       тесты формулы и проекции
```

Проверки:

```bash
node --check plugin/index.js
node --check plugin/client.js
node --test test/cost.test.mjs
```

Тесты покрывают базовую формулу, cache read/write, контекстные тарифы,
неизвестную цену, смену модели внутри хода, повторный `messageId`,
JSON-перезагрузку состояния, повреждённый кэш, peak/off-peak (текущее
поведение — множитель не применяется), временные метки сессии, валидацию
диапазона сверки и сходимость итогов.

## Известные ограничения

- Точная стоимость за запрос появится только после перехвата `x-request-id`
  (свой адаптер, прокси или изменение адаптера DSH).
- Peak/off-peak и fast mode пока не учитываются отдельно.
- Неудачные и повторные попытки могут стоить денег, но не всегда дают
  `assistant/message`; оценка может быть ниже счёта.
- При смене прайса старые сообщения не пересчитываются.
- Стоимость доступна только для сессий с сообщениями TeamoRouter.
- Сверка с billing API показывает факт по ключу за период, а не изолированную
  стоимость сессии.
