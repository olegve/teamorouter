# AGENTS.md

## Задача

Сделать плагин для DeepSeek Harness, который нативно интегрирует
[TeamoRouter](https://teamorouter.com/) как LLM-провайдера:

1. TeamoRouter должен подключаться через меню **«Модель»** в настройках DSH —
   без ручного редактирования YAML.
2. В настройках должен быть виден **баланс** аккаунта TeamoRouter.
3. Во время работы должна быть **сразу видна стоимость выполненного запроса**.

Статус: `v0.1.5` установлен в профиль `desktop`: страница «TeamoRouter»,
баланс, дневные и месячные затраты, список моделей, авто-метаданные,
стоимость сессии, хода и последнего запроса хода, а также сверка с billing
API за период сессии готовы. Краевые тесты проходят; осталась визуальная
проверка новых строк.

## Реализация

- Один bundle: Host-часть (BFF для ключа/баланса/моделей) + Client-часть
  (страница «TeamoRouter»).
- Пакет плагина: [`plugin/`](plugin/) — `package.json`, `cordis.patch.yml`,
  `index.js`, `client.js`, `locale/`, `icon.svg`.
- Страница аккаунта и сценарий подключения описаны в
  [accaunt.md](accaunt.md).
- Детали исследования — в [research.md](research.md); визуализация затрат —
  в [costs.md](costs.md).

### Сделано в v0.1.0

- Страница `settings.section` с `id: "teamorouter-account"`, `order: -9`.
- Поле API-ключа, кнопка «Подключить», проверка через `GET /v1/models`.
- Импорт чат-моделей с фильтрацией image/midjourney/jev.
- Отдельный маршрут Claude через `anthropic-messages`.
- Сохранение ключа на Host, баланс через `GET /v1/billing/balance`.
- Существующий `providers.teamorouter` не перезаписывается: модели
  дополняются, пользовательские записи сохраняются.
- Host-запись `include:teamorouter-account` активна; слот зарегистрирован.

### Сделано в v0.1.1

- `GET /costs`: фактические затраты за сегодня и текущий месяц через
  `/v1/billing/costs` и `/v1/usage`; кэш 60 секунд. Проверено на живом
  аккаунте: суммы, число запросов и токены приходят.
- Карточки «Сегодня» и «Этот месяц» на странице «TeamoRouter»: сумма,
  запросы, токены.
- Компактная строка «Баланс · Сегодня · Месяц» в карточке провайдера
  TeamoRouter на странице Models.
- Кнопка «Обновить данные» обновляет баланс и обе суммы.
- В `status` добавлен список моделей с протоколом, контекстом, vision и
  reasoning; модель можно сделать основной прямо из списка.
- При импорте моделей автоматически задаются `contextWindow`, `maxTokens`,
  `input` (text/image) и `reasoningEfforts` для известных семейств.

### Сделано в v0.1.2–v0.1.5

- Проекция `teamorouterCost` через `ctx.sessionProjections`: складывает
  `assistant/message` только для `teamorouter` и `teamorouter-anthropic`,
  считает стоимость по прайсу `/v1/models/pricing` и отдаёт клиенту
  стоимость сообщения, хода и сессии. Стоимость хранится в нано-долларах.
- В композере, в строке статистики под полем ввода, добавлен чип
  `≈ $0.1817` с иконкой TeamoRouter и подсказкой: запросы, токены,
  неоценённые запросы.
- Чип стоимости последнего запроса хода в `conversation.chat.assistant-actions`
  и строка стоимости хода в `conversation.chat.turnTail`
  (`≈ $0.012 за ход · 3 запроса · токены`).
- Клик по чипу сессии открывает сверку с `/v1/billing/costs`: факт по ключу
  за период сессии, разница, число запросов. Факт не изолирует сессию и может
  включать другие запросы.
- Корневой `package.json` описывает bundle для установки прямо из GitHub;
  `plugin/` остаётся локальной установкой. Версия `0.1.5`.
- Формула проверена на живом запросе: 31 входной / 1 выходной токен,
  расчёт совпал с фактическим списанием `$0.00000446`.
- `inputTokens` в DSH не включает cache read/write; формула использует
  `input`, `cache_read`, `cache_creation`, `output` без вычитания кэша.
- `x-request-id` — это billing `request_id`; `replayState.response.responseId`
  им не является. Для точной суммы за запрос нужен отдельный адаптер/прокси.
- Тесты формулы и проекции — [`test/cost.test.mjs`](test/cost.test.mjs),
  17 проверок: cache read/write, контекстные тарифы, неизвестная цена,
  нормализация usage, смена модели внутри хода, повтор message id,
  JSON-перезагрузка состояния, повреждённые строки кэша, peak/off-peak
  (сейчас множитель не применяется), временные метки сессии, диапазон сверки,
  итог по сообщению/ходу/сессии.

### Текущее состояние

- Страница «TeamoRouter» и баланс проверены пользователем в браузере
  (v0.1.0). Дневные/месячные суммы проверены на живом аккаунте; карточки и
  список моделей в UI ждут визуальной проверки.
- Стоимость сессии показывается в композере; стоимость хода — после хода;
  стоимость последнего запроса хода — в строке действий. Всё обновляется
  после каждого ответа TeamoRouter.
- Чип сессии открывает сверку с billing API; факт показывается как сумма по
  ключу за период и может включать другие запросы.
- Страница «TeamoRouter» обновляет дневные/месячные суммы раз в 60 секунд;
  после `turn/end` Host сбрасывает кэш, поэтому следующее обновление читает
  свежие данные.
- Краевые тесты проекции и формулы проходят. Осталась визуальная проверка
  новых строк и диалога сверки в браузере.

## Модели

- Claude автоматически идёт через `teamorouter-anthropic`
  (`anthropic-messages`), остальные — через `teamorouter`
  (`openai-completions`).
- При импорте для известных семейств задаются context/max tokens, vision
  (`input: text,image`) и reasoning levels.
- На странице «TeamoRouter» есть список моделей с протоколом и возможностями;
  кнопка «Сделать основной» сохраняет выбор через `agentDefaultModel`.
